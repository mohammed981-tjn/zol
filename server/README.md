# منسّق AdCraft (Orchestrator)

الخادم الوسيط الذي يحمل مفاتيح مزوّدي الذكاء الاصطناعي ويُخرج للتطبيق نقاط
توليد جاهزة. **التطبيق لا يحمل أي مفتاح ولا يعرف أي مزوّد** — هذه قاعدة أمنية
لا اختيارية: مفتاح داخل تطبيق قابل للاستخراج، وفاتورته على صاحب المشروع.

## التشغيل بلا أي مفتاح (للتجربة والعرض)

```bash
cd server
npm install
MOCK_MODE=1 npm run dev
```

المزوّدان المحاكيان يُنتجان نصاً عربياً واقعياً وصورة PNG حقيقية، فتُجرَّب رحلة
العميل كاملة **بلا فاتورة وبلا حساب عند أي مزوّد**.

## التشغيل بمزوّدين حقيقيين

```bash
export GEMINI_API_KEY=...        # أو ANTHROPIC_API_KEY مع TEXT_PROVIDER=anthropic
export BFL_API_KEY=...           # مزوّد الصور (FLUX)
export ALLOWED_ORIGINS=https://app.example.com
npm run build && npm start
```

### متغيرات البيئة

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `MOCK_MODE` | — | `1` لتشغيل المحاكيين بلا مفاتيح |
| `TEXT_PROVIDER` | `gemini` | `gemini` أو `anthropic` |
| `GEMINI_API_KEY` | — | مطلوب مع `gemini` |
| `GEMINI_MODEL` | `gemini-2.5-flash` | |
| `ANTHROPIC_API_KEY` | — | مطلوب مع `anthropic` |
| `BFL_API_KEY` | — | مفتاح FLUX لتوليد الصور |
| `FLUX_MODEL` | `flux-pro-1.1` | |
| `ALLOWED_ORIGINS` | منافذ محلية | قائمة أصول الويب مفصولة بفواصل |
| `PORT` | `8080` | |

> **تنبيه على الطبقة المجانية:** شروط الطبقة المجانية عند بعض المزوّدين تسمح
> باستخدام بياناتك لتحسين منتجاتهم. محتوى هذا المنتج هو **صور منتجات التجّار
> وهوياتهم** — أي بيانات عملاء. استخدم الطبقة المجانية للتجريب الداخلي فقط،
> وانقل أي محتوى تاجر حقيقي إلى طبقة مدفوعة قبل أول عميل.

## النقاط

| النقطة | الوصف |
|---|---|
| `GET /health` | حالة الخادم والمزوّدين المستخدمين |
| `GET /api/options` | النبرات والمنصات والخطط — لتتزامن الواجهة مع الخادم |
| `GET /api/usage` | حصة الحساب اليوم |
| `POST /api/generate/preview` | المعاينة الرخيصة: نص + صورة خلفية |
| `POST /api/generate/copy` | النص وحده (أرخص مسار لإعادة الصياغة) |

مثال:

```bash
curl -X POST http://localhost:8080/api/generate/preview \
  -H 'content-type: application/json' \
  -H 'x-account-id: merchant-42' \
  -d '{"productName":"قهوة مختصة","tone":"عاطفي","platform":"إنستغرام"}'
```

## قرارات معمارية

### 1. لا نطلب من نموذج الصور أن يكتب عربياً

نماذج توليد الصور تُشوّه النص العربي (حروف منفصلة أو معكوسة)، وحتى أفضلها في
رسم النص لا يُعتمد عليه للعربية بثبات. لذلك:

```
نموذج الصور  →  خلفية/مشهد المنتج فقط، وبرومبت يمنع أي حرف صراحةً
التطبيق      →  يركّب النص العربي كطبقة نصية حقيقية فوق الصورة
```

الفائدة ثلاثية: طباعة عربية صحيحة دائماً، ونص يبقى قابلاً للتعديل بعد
التوليد، وصفر إعادة توليد بسبب حروف مشوّهة. البرومبت السلبي في
`src/promptbook/image.ts` يمنع `arabic script` صراحةً.

### 2. الحدّ يُنفَّذ على الخادم قبل أي استدعاء مكلف

`src/lib/metering.ts` يحجز المعاينة **قبل** مناداة أي مزوّد. الواجهة قابلة
للتعديل، والخادم هو من يدفع. هناك اختبار يتحقق أن مزوّد الصور **لم يُستدعَ**
بعد تجاوز الحد.

### 3. لا فيديو في المعاينة

المعاينة نص + صورة (نحو ‎$0.05). الفيديو (‎$0.31–1.20 للمقطع) خلف بوابة الدفع.
هذا يحمي التكلفة ويصلح وعد السرعة في الوقت نفسه، لأن إخراج الفيديو يستغرق
عادةً من نصف دقيقة إلى ثلاث دقائق.

### 4. المزوّدون خلف محوّلات

`src/providers/` يُخفي كل مزوّد خلف واجهة، فتبديل نموذج أو شركة لا يمسّ بقية
الشيفرة — ضابطٌ لتقلّب الأسعار والتوافر.
