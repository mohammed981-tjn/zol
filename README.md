# zol
## سوق الدعاية والإعلان الشامل

منصّة تدمج الذكاء الاصطناعي التوليدي، الطباعة الميدانية، وشبكات التوصيل — لتحويل أي منتج أو فكرة تجارية إلى إعلان تسويقي رقمي (فيديو/صور) في ثوانٍ، مع خيار تحويل التصميم إلى مطبوعات مادية (استيكرات، بنرات، كروت) وتوصيلها للعميل.

## الفكرة الأساسية

1. **الذكاء الاصطناعي التوليدي**: فيديو وصور ونصوص إعلانية جاهزة في ثوانٍ.
2. **الطباعة الميدانية**: شبكة مطابع تحوّل التصميم إلى بنرات واستيكرات وكروت.
3. **شبكات التوصيل**: توصيل المطبوعات مباشرة إلى باب العميل.

## رحلة العميل

الهدف: معاينة فورية في أقل من 90 ثانية من رفع الصورة إلى الإعلان الجاهز.

1. ابدأ — زر واحد: «أنشئ إعلانك الآن»
2. أدخل التفاصيل — صورة المنتج + نبرة الإعلان + المنصة المستهدفة
3. شاشة السحر — معاينة فورية: نص وهاشتاقات وصورة (الفيديو خلف بوابة الدفع، انظر ضوابط التكلفة)
4. نفّذ — حفظ ونشر، أو اطبعه وصلّه

## نموذج الربح

- **الإعلانات الرقمية**: خطة مجانية بعلامة مائية + اشتراك شهري (29$) لفتح الميزات المتقدمة، أو نظام رصيد للشركات الكبيرة.
- **الطباعة**: تعاقد مع المطابع بأسعار الجملة، وبيع الخدمة بهامش ربح 15%–20%.
- **التوصيل**: رسوم توصيل ثابتة أو مدمجة بسعر المنتج.

## خطة التنفيذ التدريجي

1. **المرحلة الأولى — اختبار التشغيل**: التعاقد مع 3 مطابع ووكالة إعلانية واحدة، وتجربة رحلة العميل كاملة لقياس الجودة والسرعة.
2. **المرحلة الثانية — تقنية التوصيل**: ربط التطبيق بنظام توصيل خارجي أو شبكة مندوبين مستقلين.
3. **المرحلة الثالثة — توسيع السوق**: فتح باب التسجيل لما لا يقل عن 100 مطبعة ووكالة، وتفعيل نظام المنافسات.

## المعمارية

```
تطبيق Flutter  ──HTTP──▶  المنسّق (server/)  ──▶  مزوّدو الذكاء الاصطناعي
   لا مفاتيح                المفاتيح هنا              نص · صورة
```

**التطبيق لا يحمل أي مفتاح مزوّد ولا يعرف أي نموذج يُستخدم.** كل الاستدعاءات
تمر بالمنسّق، وهو من يحمل المفاتيح ويفرض حدود الاستخدام.

نماذج توليد الصور تُشوّه الحروف العربية، فلا نطلب منها رسم أي حرف: المنسّق
يعيد خلفية بلا نص، والتطبيق يركّب النص العربي فوقها طبقةً — طباعة سليمة
ونص يبقى قابلاً للتعديل.

## تطبيق Flutter

نموذج متكامل مستوحى من أفضل الممارسات العالمية (AdCreative.ai، Canva، CapCut، Printify، VistaPrint):

- **هيكل بتنقل سفلي** (`lib/screens/shell_screen.dart`) — الرئيسية، إعلاناتي، طلباتي، الإعدادات.
- **الرئيسية** (`lib/screens/home_screen.dart`) — زر «أنشئ إعلانك الآن» + إحصاءات سريعة.
- **أدخل التفاصيل** (`lib/screens/create_ad/upload_details_screen.dart`) — رفع صورة المنتج من المعرض أو الكاميرا، واسمه ووصفه، والنبرة والمنصة وصيغة الإعلان (منشور/ستوري/ريلز)، والموسم المحلي والخلفية المزخرفة.
- **شاشة السحر** (`lib/screens/create_ad/magic_screen.dart`) — توليد حقيقي عبر المنسّق: ثلاث صيغ إعلانية بزوايا مختلفة، وترشيح الوكيل الناقد، ومعالجة تجاوز الحصة وأخطاء الشبكة مع إعادة المحاولة.
- **معاينة التصميم** (`lib/widgets/ad_design_preview.dart`) — الخلفية المولَّدة أو النمط المزخرف، فوقها النص العربي كطبقة نصية بلوحة مشتقة من العلامة والموسم والمنتج.
- **التنفيذ** (`lib/screens/create_ad/execute_screen.dart`) — مسار «حفظ ونشر»، أو «اطبعه وصلّه» بكتالوج مطبوعات (بنر/استيكرات/كروت/رول أب) بمقاسات وكميات و**تسعير فوري** (منتج + توصيل + ضريبة 15%).
- **طلباتي** (`lib/screens/orders_screen.dart`) — تتبع الطلبات بخط زمني (استلام → طباعة → توصيل → تسليم).
- **إعلاناتي** (`lib/screens/my_ads_screen.dart`) — مكتبة النسخ المحفوظة.
- **الإعدادات** (`lib/screens/settings_screen.dart`) — وضع فاتح/داكن + بطاقة خطة الاشتراك.

`lib/services/ad_generator.dart` بقي مولّداً محلياً حتمياً يغذّي معرض القوالب
والمعاينات التي لا تستدعي المنسّق.

ملاحظات تقنية:

- الخطوط العربية (Tajawal وCairo وAlmarai، رخصة SIL OFL) مضمّنة في `assets/fonts/` بدل الاعتماد على تنزيلها من CDN. Tajawal خط الواجهة، والاثنان الآخران خيارا «خط العلامة التجارية».
- على الويب، يُحمَّل محرك CanvasKit من النسخة المضمّنة محليًا (انظر `web/flutter_bootstrap.js`) حتى يعمل التطبيق خلف الشبكات التي تحجب CDN جوجل.

### التشغيل

المنسّق أولاً (بلا أي مفتاح):

```bash
cd server && npm install && MOCK_MODE=1 npm run dev
```

ثم التطبيق:

```bash
flutter pub get
flutter run -d chrome --dart-define=ORCHESTRATOR_URL=http://localhost:8899
# محاكي أندرويد يستخدم 10.0.2.2 بدل localhost:
flutter run --dart-define=ORCHESTRATOR_URL=http://10.0.2.2:8899
```

```bash
flutter analyze && flutter test
cd server && npm test
```

## القرار المعماري الأهم: النص العربي لا يُرسم داخل الصورة

نماذج توليد الصور تُشوّه العربية (حروف منفصلة أو معكوسة). فبدل مصارعة النموذج:

1. نطلب منه **خلفية بلا أي حرف** (وبرومبت سلبي يمنع `arabic script` صراحةً).
2. نركّب النص العربي في التطبيق بمحرّك Flutter الذي يشكّل العربية تشكيلاً صحيحاً.

النتيجة: طباعة عربية سليمة 100%، ونص يبقى قابلاً للتعديل بعد التوليد، وصفر
إعادة توليد بسبب حروف مشوّهة. التطبيق يضمّن خط **Cairo** (رخصة OFL) فتتطابق
الطباعة على أندرويد وiOS والويب، وتتوحّد الهوية مع تطبيق ZadGo.

## ضوابط التكلفة المبنية في الشيفرة

مستمدة من دراسة الجدوى وتكلفة الوحدة الحقيقية (معاينة نص + صورة ≈ ‎$0.05، مقطع فيديو ‎$0.31–1.20):

| الضابط | الموضع |
|---|---|
| الحدّ اليومي يُنفَّذ على الخادم **قبل** أي استدعاء مكلف | `server/src/lib/metering.ts` |
| لا فيديو في المعاينة — الفيديو خلف بوابة الدفع | `PLANS[].allowExpensiveRender` |
| إمكان توليد النص وحده بلا صورة | `includeImage: false` |
| قائمة أصول صريحة لا `*` في CORS | `server/src/lib/cors.ts` |

## الخطوات التالية

- مصادقة وحساب تاجر حقيقي بدل ترويسة `x-account-id` المؤقتة.
- استبدال عدّاد الذاكرة بـ Firestore أو Redis ليصمد عبر تشغيلات الخادم.
- الدفع والاشتراكات — وهو نفسه بوابة الالتزام التي تُفتح بعدها ميزة الفيديو.
- استخراج هوية العلامة من صورة المنتج وحفظها لإعلاناته القادمة.
- ربط مسار «اطبعه وصلّه» بشبكة المطابع والتوصيل.
