# واجهة شركاء zol — توليد الإعلانات

يولّد ثلاث صيغ إعلانية عربية بزوايا مختلفة (منفعة · فضول · عرض)، ويمرّرها
على وكيل ناقد يمنح كل صيغة درجة، ثم يعيدها مرتّبة بالأفضل أولًا.

نداء واحد. لا SDK ولا اعتماديات.

## المصادقة

مفتاحك في الترويسة `X-Partner-Key`. يُعرض **مرة واحدة عند إصداره** —
لا يمكن استرجاعه لاحقًا، وإن ضاع يُصدَر بديل ويُبطَل القديم.

> لا تضع المفتاح في شيفرة عميل (متصفح أو تطبيق جوال). ناد الواجهة من
> خادمك؛ مفتاح في المتصفح مفتاحٌ منشور.

## الطلب

```http
POST https://fbbrkwragezhztffbvxf.supabase.co/functions/v1/ad-copy-partner
Content-Type: application/json
X-Partner-Key: pk_live_...
```

| الحقل | إلزامي | الوصف |
|---|---|---|
| `product` | ✅ | اسم المنتج ووصفه. كلما دقّ الوصف جاد الإعلان |
| `platform` | — | `instagram` (افتراضي) · `tiktok` · `x` · `snapchat` |
| `brief` | — | كائن حر: الفئة، الجمهور، العرض، النبرة |

```bash
curl -X POST https://fbbrkwragezhztffbvxf.supabase.co/functions/v1/ad-copy-partner \
  -H "Content-Type: application/json" \
  -H "X-Partner-Key: $ZOL_PARTNER_KEY" \
  -d '{
    "product": "عسل سدر جبلي — معبأ ٥٠٠ جم",
    "platform": "instagram",
    "brief": { "الفئة": "أغذية", "العرض": "خصم ١٥٪ هذا الأسبوع" }
  }'
```

## الرد

```json
{
  "ok": true,
  "generation_id": "…",
  "variants": [
    {
      "angle": "منفعة",
      "headline": "عسل سدر جبلي يصلك اليوم",
      "body": "…",
      "cta": "اطلب الآن",
      "hashtags": ["#عسل_سدر"],
      "score": 8.5,
      "rank": 1
    }
  ],
  "quota": { "limit": 100, "used": 12, "remaining": 88 }
}
```

الصيغ **مرتّبة**: `variants[0]` هو الأعلى درجةً عند الناقد. إن أردت واحدة
فقط فخذ الأولى؛ وإن أردت عرض خيارات على مستخدمك فاعرض الثلاث.

## الحصة

حصة شهرية ثابتة تُصفَّر مع بداية كل شهر ميلادي. **التوليدات الفاشلة لا
تُحتسب** — لا تدفع ثمن عطل عندنا.

كل رد يحمل `X-Quota-Limit` و`X-Quota-Remaining`، فتراقب استهلاكك بلا نداء
إضافي.

## الأخطاء

| الرمز | المعنى | ما تفعله |
|---|---|---|
| `401` `missing_key` / `invalid_key` | مفتاح ناقص أو غير صالح | تحقّق من الترويسة |
| `403` `partner_suspended` | الحساب موقوف | راسلنا |
| `429` `quota_exceeded` | نفدت حصة الشهر | انتظر التصفير أو اطلب رفعها |
| `400` `missing_product` | `product` فارغ | أرسل وصف المنتج |
| `502` `generation_failed` | تعذّر التوليد | أعد المحاولة؛ إن تكرّر فراسلنا |
| `503` `auth_unavailable` | عطل مؤقّت عندنا | أعد المحاولة بتراجع أسّي |

الأخطاء `502` و`503` عابرة — عالجها بإعادة محاولة متباعدة. أما `401` و
`403` و`429` فلا تُصلحها إعادة المحاولة.

## الزمن

التوليد يمرّ بكاتب ثم ناقد، فتوقّع **٥–١٥ ثانية** للنداء الواحد. لا تناده
في مسار يحجب واجهة مستخدمك — ولّد في الخلفية واعرض النتيجة عند وصولها.
