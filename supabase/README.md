# دوال Supabase

عقل المنتج المنشور. كان يعيش في لوحة Supabase وحدها ولا نسخة منه في git —
أي تعديل أو انهيار كان يعني فقدان الشيفرة. هذا المجلد يحفظه.

## `ad-copy`

يكتب ثلاث صيغ إعلانية بزوايا مختلفة (منفعة · فضول · عرض)، ثم يمرّرها على
وكيل ناقد يمنح كل صيغة درجة وملاحظة تحسين، ويرتّبها تنازلياً. يسجّل كل
توليدة في `generation_logs` بالتكلفة والرموز والزمن — وهو المصدر الذي
تقرأه لوحة الإدارة.

البرومبتات ليست في الشيفرة بل في جدول `prompts` بإصدارات، فتُعدَّل بلا نشر.

### المزوّدون

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `AI_PROVIDER` | `google` | `google` أو `openrouter` |
| `GEMINI_API_KEY` | — | مطلوب مع `google` |
| `AI_TEXT_MODEL` | `gemini-3.5-flash` | نموذج جيميناي |
| `OPENROUTER_API_KEY` | — | مطلوب مع `openrouter` |
| `OPENROUTER_MODELS` | أربعة نماذج مجانية | قائمة مفصولة بفواصل تُجرَّب بالترتيب |
| `AI_PRICE_IN` / `AI_PRICE_OUT` | `0.30` / `2.50` | سعر المليون رمز؛ يُتجاهل مع نماذج `:free` |

**سلسلة النماذج لا نموذج واحد:** النماذج المجانية على OpenRouter تُرجع 429
حين تزدحم، فنموذج واحد يعني تعطّل التوليد لا بطأه. الدالة تمرّ على القائمة
حتى ينجح واحد، وتسجّل النموذج الذي نجح فعلاً في `generation_logs`.

**التسعير:** أي نموذج بلاحقة `:free` تُحسب تكلفته صفراً، وإلا لظهرت فواتير
وهمية في لوحة الإدارة لتوليدات لم تكلّف شيئاً.

## النشر

```bash
supabase functions deploy ad-copy --project-ref <ref>
```

## إبقاء المشروع حيًّا

الخطة المجانية توقف المشروع إذا قلّ نشاط القاعدة على مدى **٧ أيام** — لا
شهرين. بعد الإيقاف تبقى مهلة ٩٠ يومًا لاستعادته يدويًا من اللوحة.

طبقتان مستقلتان تحرسانه:

| الطبقة | الملف | الوتيرة | تعمل من |
|---|---|---|---|
| `pg_cron` داخل القاعدة | `migrations/20260815000000_keepalive.sql` | كل ٨ ساعات | لحظة تطبيق الترحيل |
| GitHub Actions | `.github/workflows/supabase-keepalive.yml` | يوميًا | بعد الدمج في `main` فقط |

كلتاهما تستدعي `public.keepalive()` — دالة تعيد الوقت ولا تلمس أي جدول.
الطلب يمرّ عبر واجهة REST العامة ليُحتسب طلب مستخدم حقيقيًا، لا استعلامًا
داخليًا. السجل في `keepalive_log` (محميّ بـRLS بلا سياسات، فلا يُقرأ من
الواجهة العامة):

```sql
select ran_at, request_id from public.keepalive_log order by ran_at desc limit 10;
```
